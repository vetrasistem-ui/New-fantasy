# Content

Fonte organizada de conteúdo do jogo.

Estrutura oficial:

```text
Game/Content/
├── Items/
├── Monsters/
├── NPCs/
├── Quests/
├── Spells/
├── Classes/
├── Skills/
├── Loot/
└── Systems/
```

Os editores do Studio trabalham sobre modelos Fantasy e adapters cuidam da compatibilidade com o runtime TFS.
