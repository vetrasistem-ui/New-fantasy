# Assets

Assets do jogo e catálogo semântico Fantasy.

A família inicial é DAT + SPR + OTB 10.98, mas o projeto não deve depender de IDs soltos em lógica de alto nível. O Asset Manager futuro deverá mapear nomes semânticos para IDs concretos.

Exemplo conceitual:

```text
TREE_OAK_SMALL -> client/server item id
ROAD_STONE_A   -> client/server item id
```

O pacote de assets 10.98 será fixado por hash na F00.
