# Local legacy asset packs

This directory is reserved for user-supplied compatibility packs used by F05.5.

Do not commit third-party DAT/SPR/OTB binaries here unless redistribution rights are explicitly established.

Recommended local layout for the first profile:

```text
Game/Assets/Legacy/PokeFans1098/
├── Tibia.dat
├── Tibia.spr
└── items.otb
```

The actual filenames are configurable. The profile is authoritative for path resolution.
